# 🧠 Proyecto: Clasificador de Imágenes en la Nube

Desarrollado para la asignatura **Computación en la Nube** – Universidad Tecnológica de Honduras (UTH)  
**Docente:** Ing. Asalia Zavala  

---

## 🎯 Objetivo
Implementar un modelo básico de **Machine Learning** que identifique objetos en imágenes, desplegado en la nube con **Streamlit Cloud**.

---

## ⚙️ Herramientas utilizadas
- Google Colab → Entrenamiento del modelo
- Kaggle → Dataset CIFAR‑10
- Streamlit → Desarrollo de la interfaz
- Streamlit Cloud → Despliegue de la aplicación

---

## 🧩 Dataset
- **Nombre:** CIFAR‑10  
- **Clases:** avión, auto, pájaro, gato, ciervo, perro, rana, caballo, barco, camión  
- **Fuente:** [CIFAR‑10 en Kaggle](https://www.kaggle.com/datasets/swarooprm/cifar10-pngs-in-folders)

---

## 🚀 Pasos para reproducir
1. Entrenar el modelo en Google Colab y guardar como `modelo_cifar10.h5`.  
2. Crear archivo `app.py` con el código de Streamlit.  
3. Subir ambos archivos a un repositorio en GitHub.  
4. Desplegar en **Streamlit Cloud**.  
5. Compartir la URL pública.
